在上一讲中，我们讨论了如何将信息编码为位序列。在本次讲座中，我们将注意力转向寻找比特的有用物理表示，这是构建可以处理信息的设备的第一步。

编码信息

那么，什么才是好的， IE。，我们希望比特的物理表示具有哪些属性？

好吧，我们会想要很多。我们期望随身携带数十亿比特， 例如、音乐文件。我们期望能够访问网络上数万亿个额外的信息、娱乐、社交互动、商业——这样的例子不胜枚举。所以我们希望比特既小又便宜。

大自然提出了一个建议：DNA 中包含的化学编码，其中核苷酸序列腺嘌呤、胸腺嘧啶、鸟嘌呤和胞嘧啶形成密码子，编码遗传信息，作为生物体的蓝图。分子尺度满足我们的尺寸要求，并且正在积极研究如何利用生命化学来进行大规模有趣的计算。

我们当然希望我们的位能够在很长一段时间内保持稳定——一次为 0，永远为 0！此处展示的罗塞塔石碑是原始碑文的一部分，其中包含埃及国王托勒密五世的法令，罗塞塔石碑创建于公元前 196 年，编码了考古学家在近 2000 年后开始可靠破译埃及象形文字所需的信息。但是，石刻能够稳定地表达信息的特性使得信息的操纵变得困难。

这就引出了购物清单上的最后一项：我们希望比特的表示能够轻松快速地访问、转换、组合、传输和存储它们编码的信息。

假设我们不想随身携带一桶桶粘糊糊的 DNA 或石凿子，我们应该如何表示比特？

通过一些工程，我们可以使用与带电粒子相关的电现象来表示信息。带电粒子的存在会产生电势能差异，我们可以将其测量为电压，而带电粒子的流动可以测量为电流。我们还可以使用与带电粒子相关的电磁场的相位和频率来编码信息——后两种选择构成了无线通信的基础。哪种电现象是最佳选择取决于预期应用。

在本课程中，我们将使用电压来表示位。例如，我们可以选择0V代表0位，1V代表1位。为了表示位序列，我们可以使用多个电压测量值，可以来自许多不同的电线，也可以作为单根电线上随时间变化的电压序列。

使用电压的表示有许多优点：电源插座提供廉价且最可靠的电力来源，对于移动应用，我们可以使用电池来满足我们的需要。一个多世纪以来，我们积累了大量有关电压和电流的工程知识。我们现在知道如何构建非常小的电路来存储、检测和操纵电压。我们可以使这些电路以非常少量的电力运行。事实上，如果没有任何编码信息发生变化，我们可以设计出在稳定状态下需要接近零功耗的电路。

然而，基于电压的表示确实存在一些挑战：电压很容易受到周围环境中电磁场变化的影响。如果我想传输电压编码信息给你，我们需要通过电线连接。改变电线上的电压需要一些时间，因为带电粒子所需流动的时间是由电线的电阻和电容决定的。在现代集成电路中，这些 RC 时间常数很小，但遗憾的是不为零。

我们拥有应对这些挑战的良好工程解决方案，所以让我们开始吧！

考虑使用电压来表示黑白图像中的信息的问题。图像中的每个 (x,y) 点都有一个关联的强度：黑色是最弱的强度，白色是最强的。一个明显的基于电压的表示是将强度编码为电压，例如黑色为 0V，白色为 1V，以及中间强度的一些中间电压。

第一个问题：图像中每个点有多少信息？答案取决于我们区分强度的能力，或者在我们的例子中，区分电压的能力。如果我们能够区分任意小的差异，那么图像的每个点都可能包含无限量的信息。但是，作为工程师，我们怀疑我们可以检测到的差异大小存在下限。

为了表示与 N 位可以表示的相同信息量，我们需要能够区分 0V 到 1V 范围内总共 $2^N$ 个电压。例如，对于 N = 2，我们需要能够区分四种可能的电压。这看起来并不太难——一个便宜的电压表可以让我们轻松区分 0V、1/3V、2/3V 和 1V。

理论上，N可以是任意大。在实践中，我们知道以百万分之一伏的精度进行测量将是相当具有挑战性的，如果我们想要十亿分之一伏的精度，则可能几乎是不可能的。不仅设备开始变得非常昂贵，测量也非常耗时，而且我们会发现热噪声等现象会混淆我们所说的特定时间瞬时电压的含义。

因此，我们使用电压编码信息的能力显然会受到我们在特定时间可靠且快速区分电压的能力的限制。

为了完成我们呈现完整图像的项目，我们将以某种规定的光栅顺序（从左到右、从上到下）扫描图像，同时将强度转换为电压。这样，我们就可以将图像转换为随时间变化的电压序列。这就是原始电视的工作原理：图像被编码为电压波形，该电压波形在黑色和白色的表示之间变化。实际上，电压范围已扩大，以允许信号指定水平扫描的结束和图像的结束，即所谓的同步信号。我们称其为 连续波形 指示它可以在特定时间点采用指定范围内的任何值。

现在让我们看看当我们尝试构建一个系统来处理这个信号时会发生什么。

我们将使用两个简单的处理块创建一个系统。 COPY 块在其输出上再现其输入上出现的任何电压。 COPY 块的输出看起来与原始图像相同。当输入电压为 V 时，INVERTING 模块会产生 1V 电压， IE。，白色转换为黑色，反之亦然。通过 INVERTING 块后，我们得到输入图像的负片。

为什么要有处理块？使用预封装的块是构建大型电路的一种常见方法——我们可以通过将块相互连接来组装一个系统，并推理所得系统的行为，而无需了解每个块的内部细节。这些模块提供的预封装功能使它们易于使用，而无需成为专业的模拟工程师！

此外，我们希望在构建不同的系统时能够以不同的配置连接模块，并能够根据每个模块的行为来预测每个系统的行为。这将使我们能够构建像修补玩具一样的系统，只需将一个块连接到另一个块即可。即使是不了解电气细节的程序员也可能期望构建执行某些特定处理任务的系统。

整个想法是保证可预测的行为：如果组件工作并且我们按照连接块的任何规则将它们连接起来，我们将期望系统按预期工作。

那么，让我们用 COPY 和 INVERTING 块构建一个系统。这是一个图像处理系统，每个块使用几个实例。我们期望输出图像是什么样的？

嗯，复制块不会改变图像，并且反转块的数量是偶数，因此，理论上，输出图像应该与输入图像相同。

但实际上，输出图像并不是输入图像的完美副本，它有点模糊——强度略有偏差，看起来强度的急剧变化已经被平滑，从而产生了原始图像的模糊再现。出了什么问题？

为什么理论与现实不符？

也许 COPY 和 INVERTING 块无法正常工作？这几乎肯定是正确的，因为他们并没有严格遵守对其行为的数学描述。微小的制造变化和不同的环境条件将导致 COPY 块的每个实例对于 V 伏输入产生的不是 V 伏，而是 V + epsilon 伏，其中 epsilon 表示处理过程中引入的误差量。 INVERTING 块也是如此。

困难在于，在强度的连续值表示中，V+epsilon 是一个完全正确的输出值，只是不适用于 V 伏输入！换句话说，对于稍微不同的图像，我们无法区分稍微损坏的信号和完全有效的信号。

更重要的是——这是真正的杀手——当编码图像通过复制和反转块系统时，错误会累积。系统越大，累积的处理误差量就越大。这看起来不太好：至少可以说，如果我们必须制定规则，规定在结果变得太损坏而无法使用之前可以对编码信息执行多少次计算，那会很尴尬。

如果您认为这意味着我们用来描述系统运行的理论是不完善的，那么您是对的。我们确实需要一个非常复杂的理论来捕获输出信号与其预期值不同的所有可能方式。我们这些有数学头脑的人可能会抱怨“现实是不完美的”。但这有点远了。现实就是这样，作为工程师，我们需要构建我们的系统，以便在现实世界中可靠运行。所以也许真正的问题在于我们如何选择设计系统。

事实上，以上这些都是真的！噪音和不准确是不可避免的。我们无法可靠地再现无限的信息。如果要可靠地处理信息，我们必须设计我们的系统来容忍一定数量的错误。基本上，我们需要找到一种方法来注意到处理步骤引入了错误，并在错误有机会累积之前恢复正确的值。如何做到这一点是我们的下一个主题。

数字抽象

为了解决我们的工程问题，我们将引入我们所说的 数字抽象。关键的见解是使用连续的电压世界来表示一些小的、有限的值集，在我们的例子中，是两个二进制值 0 和 1。请记住，世界本质上并不是数字的，我们只是想将其设计为以这种方式运行，使用连续的物理现象来实现数字设计。

顺便说一句，让我提一下，有些物理现象本质上是数字化的， IE。，观察到具有几个量化值之一， 例如，电子的自旋。这让古典物理学家感到惊讶，他们认为物理值的测量是连续的。描述亚原子粒子所经历的有限自由度的量子理论的发展彻底改变了经典物理学的世界。我们现在刚刚开始研究如何将量子物理学应用于计算，并且在构建量子计算机方面有有趣的进展需要报告。但在本课程中，我们将重点关注如何使用经典的连续现象来创建数字系统。

以数字方式使用电压的关键思想是采用一种信号约定，一次仅编码一位信息， IE。，两个值之一，0 或 1。我们将为数字系统中的每个组件和电线使用相同的统一表示。

我们需要进行三次尝试才能得到解决所有问题的电压表示。我们的第一个切点是显而易见的：简单地将电压范围分为两个子范围，一个范围代表 0，另一个范围代表 1。选择一些阈值电压 $V_{\textrm{th}}$，将范围一分为二。当电压 V 小于阈值电压时，我们将其表示为 0。当电压 V 大于或等于阈值电压时，它将表示为 1。这种表示方式为所有可能的电压分配了一个数字值。

该定义的问题部分是难以解释阈值附近的电压。给定特定电压的数值，很容易应用规则并得出相应的数字值。但随着电压越来越接近阈值，准确确定正确的数值会变得更加耗时且昂贵。所涉及的电路必须由精密元件制成，并在精确控制的物理环境中运行——当我们考虑到多种环境以及我们想要构建的系统的适度成本预期时，这是很难实现的。

因此，尽管这个定义在数学上很简单，但在实际应用中却行不通。这个有一个红色的大X。

在我们的第二次尝试中，我们将引入两个阈值电压：$V_{\textrm{L}}$ 和 $V_{\textrm{H}}$。小于或等于 $V_{\textrm{L}}$ 的电压将被解释为 0，大于或等于 $V_{\textrm{H}}$ 的电压将被解释为 1。$V_{\textrm{L}}$ 和 $V_{\textrm{H}}$ 之间的电压范围称为 禁区，我们禁止询问我们的数字系统的任何特定行为。特定系统可以将禁止电压解释为 0 或 1，甚至不需要其解释保持一致。事实上，系统根本不需要对此范围内的电压产生任何解释。

这有什么帮助？现在我们可以构建一个快速而肮脏的电压位转换器，例如通过使用高增益运算放大器和禁止区域中某处的参考电压来确定给定电压是高于还是低于阈值电压。该参考电压不必非常精确，因此可以使用由低成本 10% 精度电阻器构建的分压器来生成它。随着工作温度的变化或电源电压的变化等，参考值可能会略有变化。我们只需要保证转换器在电压低于 $V_{\textrm{L}}$ 或高于 $V_{\textrm{H}}$ 时的正确行为。

这种表示方式非常有前途，我们现在暂时给它一个绿色的复选标记。经过更多讨论后，我们需要再做一个小调整，然后才能到达我们想要去的地方。

我们现在可以定义数字处理元素的含义。我们说设备是 组合装置 如果满足以下四个条件：

首先，它应该具有数字输入，这意味着设备使用我们的信号约定，将低于 $V_{\textrm{L}}$ 的输入电压解释为数字值 0，将高于 $V_{\textrm{H}}$ 的电压解释为数字值 1。

其次，设备的输出也应该是数字的，通过产生小于或等于 $V_{\textrm{L}}$ 的电压来产生输出 0，通过产生大于或等于 $V_{\textrm{H}}$ 的电压来产生输出 1。

有了这两个标准，我们应该能够将一个组合设备的输出连接到另一个组合设备的输入，并期望在它们之间传递的信号被正确地解释为 0 和 1。

接下来，组合设备需要具有功能规范，详细说明输入上数字值的每种可能组合的每个输出值。

在该示例中，该设备具有三个数字输入，并且由于每个输入可以采用两个数字值之一，因此存在 2*2*2 或八种可能的输入配置。因此，对于所有 8 个输入模式，功能规范只需告诉我们输入为 000 时输出 Y 的值，以及输入为 001 时输出的值，依此类推。一个包含八行的简单表格就可以解决问题。

最后，组合设备有一个时序规范，它告诉我们设备的输出需要多长时间才能反映其输入值的变化。至少，必须有一个名为 $t_{\textrm{PD}}$ 的传播延迟规范，它是从输入达到稳定有效的数字值到保证输出具有稳定有效的输出值的时间上限。

总的来说，我们将这四个标准称为 静态纪律，所有组合设备都必须满足这一点。

为了从组合组件构建更大的组合系统，我们将遵循上图中列出的组合规则。

首先，系统的每个组件本身必须是一个组合设备。

其次，每个组件的每个输入必须连接到系统输入，或者恰好连接到另一个设备的一个输出，或者连接到代表值 0 或值 1 的恒定电压。

最后，互连的组件不能包含任何有向循环， IE。，从输入到输出的系统路径最多只会访问特定组件一次。

我们的主张是，使用这些组合规则构建的系统本身就是组合设备。换句话说，我们可以用组合组件构建大型组合设备。与讲座一开始我们的片状模拟系统不同，该系统可以是任何大小，并且仍然需要遵守静态规则。

为什么这是真的？

要了解为什么该说法是正确的，请考虑以下由组合设备 A、B 和 C 构建的系统。让我们看看是否可以证明整个系统（如包含的蓝色框所示）本身是组合的。我们将通过证明整个系统实际上遵守静态规则来做到这一点。

首先，整个系统是否有数字输入？是的！系统的输入是某些组件设备的输入。由于组件是组合的，因此具有数字输入，因此整个系统具有数字输入。在这种情况下，系统从其组件的属性继承其属性。

其次，整个系统是否有数字输出？是的，出于同样的原因：系统的所有输出都连接到其中一个组件，并且由于组件是组合的，因此输出是数字的。

第三，我们能否得出整个系统的功能规范， IE。，我们可以为每个数字输入值组合指定预期输出值吗？是的，我们可以通过组件模块增量传播有关当前输入值的信息。在所示的示例中，由于 A 是组合的，因此我们可以使用 A 的函数规范在给定其输入值的情况下确定其输出值。现在我们知道了 B 的所有输入的值，并且可以使用其功能规范来确定其输出值。最后，由于我们现在已经确定了 C 的所有输入的值，因此我们可以使用 C 的函数规范来计算其输出值。一般来说，由于电路中没有周期，我们可以通过按照电路拓扑确定的顺序评估组合组件的行为来确定每个内部信号的值。

最后，我们可以使用组件的传播延迟来推导出系统的传播延迟 $t_{\textrm{PD}}$ 吗？同样，由于没有循环，我们可以枚举从系统输入到系统输出的有限长度路径。然后，我们可以通过对沿路径的各个分量的 $t_{\textrm{PD}}$ 求和来计算沿特定路径的 $t_{\textrm{PD}}$ 。考虑到从输入到输出的所有可能路径，整个系统的 $t_{\textrm{PD}}$ 将是路径 $t_{\textrm{PD}}$s 的最大值，即最长此类路径的 $t_{\textrm{PD}}$。

因此，整个系统实际上遵守静态规则，因此它确实是一个组合设备。非常简洁——我们可以使用我们的组合规则来构建任意复杂度的组合设备。

处理噪音

在最终确定信号规范之前，我们还需要处理一个问题。考虑以下组合系统，其中左侧的上游组合设备尝试将数字 0 发送到右侧的下游组合设备。上游设备生成的输出电压略低于 $V_{\textrm{L}}$，根据我们提出的信令规范，该电压符合数字 0 的表示形式。

现在假设一些电噪声稍微改变了电线上的电压，使得下游设备的输入端检测到的电压略高于 $V_{\textrm{L}}$， IE。，接收到的信号不再符合有效数字输入的条件，并且下游设备的组合行为不再得到保证。

糟糕，由于存在少量电噪声，我们的系统运行不正常。我们希望通过采用数字系统架构来避免这种不稳定的行为。

解决该问题的一种方法是调整信令规范，使输出必须遵守比输入更严格的界限，其想法是确保有效的输出信号可以受到噪声的影响而不会变成无效的输入信号。

我们能否通过某种方式避免噪音来完全避免这个问题？这是一个不错的想法，但如果我们计划使用电气元件，这不是我们可以实现的目标。电压噪声（我们将其定义为偏离标称电压值的变化）来自多种来源。

  • 噪声可能是由电气效应引起的，例如由于欧姆定律导致的导体中的 IR 压降、导体之间的电容耦合以及由组件引线中的电感和电流变化引起的 L(dI/dt) 效应。
  • 电压偏差可能是由于组件参数与其标称值的制造差异造成的，从而导致器件之间的电气行为出现微小差异。
  • 电压可能受到环境因素的影响，例如热噪声或外部电磁场的电压效应。

名单还在继续！请注意，在许多情况下，噪声是由电路的正常运行引起的，或者是用于制造电路的材料和工艺的固有属性，因此是不可避免的。然而，我们可以预测噪声的大小并适当调整我们的信号规范——让我们看看这是如何工作的。

我们提出的噪声问题解决方案是为数字输入和数字输出提供单独的信号规范。要发送 0，数字输出必须产生小于或等于 $V_{\textrm{OL}}$ 的电压；要发送 1，则必须产生大于或等于 $V_{\textrm{OH}}$ 的电压。到目前为止，这似乎与我们之前的信号规范没有太大不同......

不同之处在于数字输入必须遵循不同的信号规范。输入电压小于或等于 $V_{\textrm{IL}}$ 必须解释为数字 0，输入电压大于或等于 $V_{\textrm{IH}}$ 必须解释为数字 1。

选择这四个信令阈值的值以满足此处所示的约束。请注意，$V_{\textrm{IL}}$ 严格大于 $V_{\textrm{OL}}$，而 $V_{\textrm{IH}}$ 严格小于 $V_{\textrm{OH}}$。输入和输出电压阈值之间的差距称为 噪声容限。噪声容限告诉我们可以向有效 0 或有效 1 输出信号添加多少噪声，并且仍然可以在其连接的输入处正确解释结果。两个噪声容限中较小的一个称为 抗噪声能力 信令规范。作为数字工程师，我们的目标是设计信号规范，以提供尽可能多的抗噪能力。

遵守此信号规范的组合设备可以在噪声有机会积累并最终导致信号错误之前消除其输入上的噪声。底线：数字信号不会遇到我们在之前的模拟信号示例中看到的问题！

让我们使用最简单的组合设备之一进行一些测量：缓冲器。缓冲器具有单个输入和单个输出，在一些小的传播延迟之后，输出将被驱动为与输入相同的数字值。该缓冲器遵循静态规则（这就是组合的含义），并使用我们修订的信令规范，其中包括低噪声容限和高噪声容限。

通过将输入电压设置为从 0V 到电源电压的一系列值来进行测量。将输入电压设置为特定值后，我们将等待输出电压变得稳定， IE。，我们将等待缓冲区的传播延迟。我们将结果绘制在图表上，横轴为输入电压，纵轴为测得的输出电压。所得曲线称为缓冲器的电压传输特性。为了方便起见，我们在两个轴上标记了信号阈值。

在我们开始绘制点之前，请注意静态规则限制了任何组合设备的电压传输特性必须是什么样子。如果我们等待设备的传播延迟，如果输入电压是有效数字值，则测量的输出电压必须是有效数字值——“有效输入，有效输出”。我们可以在图表上将其显示为阴影禁区。这些区域中的点对应于有效的数字输入电压，但对应于无效的数字输出电压。因此，如果我们测量合法的组合设备，其电压传输特性中的任何点都不会落在这些区域内。

好的，回到我们的缓冲区：将输入电压设置为小于低输入阈值 $V_{\textrm{IL}}$ 的值，产生的输出电压小于 $V_{\textrm{OL}}$，正如预期的那样 - 数字 0 输入产生数字 0 输出。尝试稍高但仍然有效的 0 输入会得到类似的结果。请注意，这些测量结果并没有告诉我们有关缓冲区速度的任何信息，它们只是测量设备的静态行为，而不是其动态行为。

如果我们继续进行所有附加测量，我们将获得缓冲器的电压传输特性，如图中的黑色曲线所示。请注意，曲线没有穿过阴影区域，满足我们上面对合法组合设备的行为提出的期望。

关于电压传输特性，有两个有趣的观察结果。

让我们更仔细地观察图表中心的白色区域，对应于 $V_{\textrm{IL}}$ 到 $V_{\textrm{IH}}$ 范围内的输入电压。首先请注意，这些输入电压处于我们的信号规范的禁区中，因此组合设备可以产生它喜欢的任何输出电压，并且仍然遵守静态规则，这仅限制设备对*有效*输入的行为。

其次，请注意，由四个电压阈值界定的中心白色区域的高度大于宽度。这是正确的，因为我们的信令规范具有正噪声容限，因此 $V_{\textrm{OH}}$ — $V_{\textrm{OL}}$ 严格大于 $V_{\textrm{IH}}$ — $V_{\textrm{IL}}$。任何穿过该区域的曲线（VTC 必须如此）都必须具有曲线斜率大于 1 的部分。在 VTC 斜率大于 1 的点，请注意，输入电压的微小变化会导致输出电压发生较大变化。这就是斜率大小大于 1 时的含义。用电气术语来说，我们可以将器件称为增益大于 1 或小于 -1 的器件，其中我们将增益定义为给定输入电压变化时输出电压的变化。

如果我们考虑用组合组件构建更大的电路，任何输出都可能连接到其他输入。这意味着水平轴上的范围 ($V_{\textrm{IN}}$) 必须与垂直轴上的范围 ($V_{\textrm{OUT}}$) 相同， IE。，VTC 的图形必须是正方形，并且 VTC 曲线适合正方形内。为了适应平方范围，VTC 必须在某个点改变斜率，因为我们从上面知道必须存在斜率大小大于 1 的区域，并且在整个输入范围内不能大于 1。在其工作范围内表现出增益变化的器件称为非线性器件。

这些观察结果告诉我们，我们不能仅使用电阻器、电容器和电感器等线性器件来构建组合器件。我们需要增益 > 1 的非线性设备。找到这样的设备是下一讲的主题。

让我们看一个具体的例子。该图显示了特定设备的电压传输特性，我们想知道是否可以将该设备用作组合逆变器。换句话说，我们是否可以选择电压阈值 $V_{\textrm{OL}}$、$V_{\textrm{IL}}$、$V_{\textrm{IH}}$ 和 $V_{\textrm{OH}}$ 的值，以便显示的 VTC 满足对组合设备施加的约束？

当反相器的输入为数字 0 时，反相器输出数字 1，反之亦然。事实上，当该设备的输入电压较低时，它确实会产生高输出电压，因此这有可能成功。

该器件产生的最低输出电压为 0.5V，因此如果器件要产生合法的数字输出 0，我们必须选择 $V_{\textrm{OL}}$ 至少为 0.5V。

我们希望反相器在其输入为有效数字 1 时产生有效数字 0。查看 VTC，我们发现如果输入高于 3V，则输出将小于或等于 $V_{\textrm{OL}}$，因此让我们将 $V_{\textrm{IH}}$ 设置为 3V。我们可以将其设置为高于 3V 的值，但我们会将其设置得尽可能低，以便为较高的噪声容限留出空间。

这涉及四个信号阈值中的两个：$V_{\textrm{OL}}$ 和 $V_{\textrm{IH}}$。其他两个阈值通过噪声容限 N 与这两个阈值相关，如这两个方程所示。我们能否找到一个 N 值，使得当 $V_{IN} \le V_{IL}$ 时 $V_{OUT} \ge V_{OH}$ ？如果我们选择 N = 0.5V，则公式告诉我们 $V_{\textrm{IL}}$ = 1V 且 $V_{\textrm{OH}}$ = 3.5V。将这些阈值绘制在图表上并添加禁止区域，我们很高兴地看到 VTC 实际上是合法的！

因此，如果我们使用信号规范 $V_{\textrm{OL}}$ = 0.5V、$V_{\textrm{IL}}$ = 1V、$V_{\textrm{IH}}$ = 3V 和 $V_{\textrm{OH}}$ = 3.5V，则可以将该器件用作组合逆变器。我们很高兴出发！
