## 本地浏览

你可以只用本机浏览这些课程资料。初次准备完成后，不需要互联网连接。

1. 将本仓库克隆到本地电脑。
2. 安装 [python3](https://www.python.org/downloads/)。
3. 切换到仓库根目录。
4. 执行下面的命令，启动监听 `8000` 端口的本地 HTTP 服务：

   ```bash
   python3 -m http.server
   ```

5. 在浏览器中打开 [http://localhost:8000/zh-CN/](http://localhost:8000/zh-CN/)，查看中文课程入口。
